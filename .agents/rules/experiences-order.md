# Regole Ordinamento Esperienze

- Nella sezione delle esperienze (es. `experiences.html`), sia attive che passate:
  - Posizionare **sempre prima i server Minecraft** (quelli con `MC` o server di gioco Minecraft, es. `RedisMC`, `MetaMc`, `PixyMC`).
  - Posizionare **dopo tutto il resto** (es. tierlist come `Elysian Tierlist`, community o altri ruoli non-server MC).
